# Fundamentals of IoT – Laboratory Repository

## About
This repository contains the laboratory experiments and practical implementations completed as part of the **Fundamentals of Internet of Things (FIoT) Lab** coursework at Shiv Nadar University, Chennai.

The repository is organized according to the CAT (Continuous Assessment Test) numbers and the corresponding hands-on exercises specified in the coursework.

## Repository Structure

```text
FIoT_LAB/

├── STM32/
```

*Note: The structure will be updated as experiments are completed.*

## Technologies and Tools
- STM32CubeMX
- Keil MDK-ARM
- STM32F103C8T6 Blue Pill
- Embedded C
- GPIO and STM32 HAL Libraries

## Experiment Documentation
Each experiment folder contains the relevant source code, project configuration files, circuit diagrams and an individual README documenting the experiment.

## Purpose
This repository serves as a record of the IoT laboratory experiments, their implementation, hardware configurations and observations.
