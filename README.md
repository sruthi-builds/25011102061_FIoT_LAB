# Fundamentals of IoT – Laboratory Repository

## About

This repository contains the laboratory experiments and practical implementations completed as part of the **Fundamentals of Internet of Things (FIoT) Lab** coursework at **Shiv Nadar University, Chennai**.

The repository is organized according to the CAT (Continuous Assessment Test) numbers and the corresponding hands-on exercises specified in the coursework. It includes experiments implemented using both **8051 microcontrollers** and **STM32 microcontrollers**.

## Technologies and Tools

The experiments in this repository use the following platforms, tools and technologies:

- **8051 Microcontroller**
- **STM32F103C8T6 Blue Pill**
- STM32CubeMX
- Keil MDK-ARM
- Embedded C
- STM32 HAL Libraries
- GPIO, UART, I2C and other peripheral interfaces
- ESP8266 Wi-Fi module
- MQTT communication
- BME280 environmental sensor

## Experiment Documentation

Each experiment folder contains the relevant files, wherever applicable:

- Embedded C source code
- Microcontroller project and configuration files
- Circuit diagrams
- Individual README documenting the experiment
- Observations and implementation details

The experiments are arranged by CAT number, with individual tasks organized within their respective CAT folders.

## Purpose

This repository serves as a record of the IoT laboratory experiments, practical implementations and hardware interfacing exercises completed throughout the coursework.

It documents the use of microcontrollers, peripheral communication protocols, sensors, wireless connectivity and IoT communication techniques through hands-on experimentation.
